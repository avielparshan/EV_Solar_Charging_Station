# 🔋 Solar-Powered EV Charging Station (Home-Based)

This project models and simulates a **solar-powered electric vehicle (EV) charging station** using MATLAB, Simulink, and Simscape. The first stage focuses on a **stationary installation** in a residential parking space, powered by photovoltaic (PV) panels.

---

## 🧭 Project Goals

- Simulate an efficient solar-powered charging system for an electric vehicle
- Implement maximum power point tracking (MPPT) control for the solar array
- Model DC-DC converters and charge controllers
- Simulate battery storage and vehicle charging profiles

---

## 🧰 Tools & Environment

- **MATLAB & Simulink**
- **Simscape / Simscape Electrical**
- **Power Electronics & Battery Simulation Toolboxes**

## 🚗 Stage 1: Home-Based Charging System

- Solar PV panels mounted on rooftop (static setup)
- DC/DC converter with MPPT controller
- Battery storage (optional)
- Charging output to EV
- Includes load cases: sunny day, cloudy day, partially charged battery
